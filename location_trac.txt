            |--------------------------------------------------------------------------
            */

            $filterType = $request->input(
                'filter_type',
                'month'
            );

                $startDate = $request->filled('start_date')
                    ? Carbon::parse($request->start_date)->startOfDay()
                    : now()->startOfMonth();

                    ? Carbon::parse($request->end_date)->endOfDay()
                    : now()->endOfDay();

                    );

                    $monthDate = now();

                    ->startOfMonth();

                $endDate = $monthDate
                    ->copy()
                    ->endOfMonth();

            |--------------------------------------------------------------------------
            | Prevent Invalid Date Range
            |--------------------------------------------------------------------------
            */

                    'message' => 'Start date cannot be greater than end date.',

            |
            */

                ]

14. When clicking a call, keep the staff filter

Your existing marker popup calls:

highlightLocationCalls(
    location.location_key
);

When a staff filter is active, highlightLocationCalls() should only highlight calls belonging to that staff.

Modify the filtering condition:

function isCallVisibleForActiveStaff(call)
{
    if (!activeStaffMapFilter) {
        return true;
    }


    return String(
        call.staff_id
    ) === String(
        activeStaffMapFilter
    );
}

Then when rendering/highlighting:

if (
    !isCallVisibleForActiveStaff(call)
) {
    return;
}

This prevents Staff A's selected map location from highlighting Staff B's calls at the same GPS coordinate.

currentData =
